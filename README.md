# مساعد محلي لتصميم تيجان الأسنان بالذكاء الاصطناعي

## عن المشروع

يهدف المشروع إلى تطوير نظام ذكاء اصطناعي محلي يساعد فني الأسنان على تصميم تاج مخصص من مسح الفم ثلاثي الأبعاد. الفكرة أن يقرأ النظام ملف حالة exocad المحفوظ بعد تحديد خط الـ margin، مع ملفات المسح المرتبطة بالحالة، ثم يولّد تاجًا بصيغة STL لفتحه ومراجعته في exocad.

النظام موجّه ليكون أداة مساعدة للتصميم. يبقى اعتماد التاج وتعديله ضمن مراجعة فني الأسنان.

## الأساس التقني

ندرس تكييف مشروع [MADCrowner](https://github.com/lullcant/MADCrowner) كنقطة بداية، بدل بناء نموذج ثلاثي الأبعاد من الصفر. المشروع البحثي يحتاج إلى تكييف ليتوافق مع ملفات Medit وexocad وطريقة تنظيم بياناتنا.

نسخة المصدر المرجعية موجودة في `third_party/MADCrowner`، ومعلومات commit المصدر والتراخيص موثقة في [`UPSTREAM_SOURCE.md`](third_party/MADCrowner/UPSTREAM_SOURCE.md).
